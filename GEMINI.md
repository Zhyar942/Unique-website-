# Workspace Instructions & Permanent Rules

## Typography Rule (Strict Enforcement)

1. **Kurdish Font — Zain**:
   - The primary font for all Kurdish text is **Zain**.
   - Sourced via Google Fonts (`font-family: 'Zain', 'Noto Sans Arabic', system-ui, sans-serif`).

2. **Font Weight — Always Normal (400)**:
   - Always use `font-weight: normal` across **all languages** (Kurdish, Arabic, English).
   - Always use `font-weight: normal` across **all situations** (h1-h6 headings, buttons, body copy, product cards, categories, navigation, inputs, badges).
   - Never use bold, semi-bold, or heavy font weights.
